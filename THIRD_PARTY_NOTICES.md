# Third-party notices

Code and assets from others that ship in the plugin, and where each licence is. Installers must include these
licence texts (the BSD-style ones require it for binary redistribution).

| Component | Used for | Licence |
|---|---|---|
| PFFFT (`libs/pffft`, a submodule of https://github.com/marton78/pffft) | The real FFT in Constant mode on Windows and Linux (`src/dsp/RealFft.h`) | BSD-style (FFTPACK / NCAR): `libs/pffft/LICENSE.txt` |
| DSEG font | UI readouts | SIL OFL 1.1: `assets/fonts/licenses/DSEG-OFL.txt` |
| IBM Plex Mono | UI text | SIL OFL 1.1: `assets/fonts/licenses/IBMPlexMono-OFL.txt` |

JUCE (`libs/JUCE`) is used under its own licence terms; which tier applies is a release decision (`HANDOVER.md`).
